## Run 
```
TRTR: Train on real emails and test on real emails.
TSTR: Train on synthetic phishing emails and real legitimate emails, then test on real emails.
Data augmentation: Combine real and synthetic phishing emails for training, then test on real
```
## Classifiers used 
```
Logistic Regression
Linear SVM
Random Forest
Multinomial Naive Bayes
```
## Project setup

### Libraries required
`pip install pandas numpy scikit-learn scipy`
### Run TRTR
`python seqgan.py --data src/dataset/SpamAssasin.csv`
### Run TSTR
`We need a CSV containing synthetic phishing emails generated by our SeqGAN model.`
```
python seqgan.py \
    --data src/dataset/SpamAssasin.csv \
    --synthetic src/dataset/seqgan_phishing.csv \
    --label-col label \
    --text-col body
```

```
<b>Important:</b> For a valid experiment, SeqGAN must be trained only on the real phishing emails in the corresponding training partition. Do not generate synthetic emails using the complete dataset before separating the test set. The script uses the same synthetic CSV across seeds, so this is suitable for an initial experiment, but for strict five-seed evaluation, generate separate synthetic datasets from each seed's training partition.
```
